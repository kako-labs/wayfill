# 뽀동이 V2 캐릭터·제품 화면 방향

## 이번 비교에서 확인한 품질 기준

Motion Care 결과물은 큰 히어로 메시지, 실제 상태를 설명하는 보조 카드, 일관된 아이콘과 테두리, 화면 전체를 묶는 조명·배경 장면이 함께 작동한다. 정보가 많아도 `현재 상태 → 근거 → 행동 → 상세 기록` 순서가 유지되고, 차량 화면에서 누를 영역과 읽을 영역이 분명하다.

Fuel Pilot V2는 이를 그대로 복사하지 않고 다음처럼 번역한다.

- 정차 홈: 경로 분석 결과, 연료 상태, 추천 주유소와 행동을 한 화면에 배치한다.
- 주행 중: 기존 정책대로 작은 아바타와 핵심 정보만 남긴다.
- 지도: 새 지도를 만들지 않고 차량 내비게이션 화면에 결과만 전달한다.
- 실제 값: 차량/경로 데이터가 없으면 예시 수치로 대체하지 않는다.
- 추천 근거: 도달 가능성, 실제 경로 추가 시간, 여유거리를 나누어 보여준다.

구현 시안은 `web/product-vision.html`에서 확인한다.

## 뽀동이 V2 마스터

선정한 마스터는 `web/assets/podong-v2-master-concept.png`다. 팀원 최초 시안과 기존 운영 캐릭터를 함께 참고해 built-in imagegen으로 만들었다.

유지한 정체성:

- 꿀빛 노란 물방울/젤리 몸
- 머리 위 한 개의 물방울 꼭지
- 분홍 볼, 짙은 갈색 눈과 입
- 짧은 손발과 별 반짝임
- 메시지 옆에서 반응하는 긍정적 성격

개선한 부분:

- 몸의 중심을 낮추고 가로로 더 말랑하게 정리
- 양발을 바닥에 두어 차량 UI에서 차분한 인상 유지
- 플라스틱 광택을 줄이고 부드러운 젤리·클레이 재질로 변경
- 작은 크기에서도 표정이 읽히도록 얼굴과 볼의 대비 정리
- 손과 팔다리를 줄여 더 포근하고 안정적인 비율로 변경

## 운영 리소스 전환 순서

현재 72프레임 운영 아틀라스는 아직 교체하지 않았다. 한 장의 시안만 먼저 넣으면 웹과 Android 모션의 정체성이 갈라지기 때문이다.

1. V2 마스터 외형 승인
2. calm/recommend/small/full/recovery의 핵심 포즈 시트 제작
3. 기존 타이밍과 고정 viewport를 유지한 72프레임 제작
4. 웹 아틀라스와 Android drawable을 동시에 교체
5. 중복 이벤트, 주행 취소, reduced-motion 및 작은 크기 가독성 재검증

## 생성 프롬프트 요약

`stylized-concept` 방식으로 기존 정체성을 유지한 고품질 3D 마스터를 만든 뒤, `precise-object-edit`으로 광택을 줄이고 몸을 낮고 넓게, 양발이 닿은 차분한 자세, 작은 손과 입으로 보정했다. 출력은 투명 배경 32-bit PNG다.
