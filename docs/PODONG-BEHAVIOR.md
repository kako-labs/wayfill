## 주유 완료 기본 시퀀스

위 시간은 원본의 연출 계획이며 GIF의 프레임 타이밍을 분석한 결과는 아니다. 화면의 GIF는 반복 재생되는 레퍼런스이고, 실제 앱의 주유 완료 이벤트에서는 한 번만 재생하는 기준으로 연결한다.

## 위치와 재생 조건

- FUEL PILOT 카드/위젯 가장자리에 몸 일부가 가려지도록 배치한다. 허공에 떠 있는 이미지 대신 카드 안에 살고 있다는 인상을 유지한다.
- 큰 캐릭터와 완료 모션은 주유 완료가 확인된 정차 상태에서만 표시한다.
- 출발하면 재생 중이라도 즉시 큰 모션을 중단하고 큰 모션을 즉시 제거한다. 주행 중에는 위젯만 남기며, 원본의 몸 일부가 남는 퇴장 연출은 아직 구현하지 않았다.
- 소리는 기본 꺼짐. 주행 중 경고를 춤이나 반복 모션으로 강조하지 않는다.
- 네이티브 지도 위 표시 권한은 아직 확인되지 않았다. 구현 시 가능한 표면을 검증하고, 불가능하면 앱 내부 카드에서 재생한다.

## 원본의 상황별 변주

- 거의 빈 연료에서 가득: 허겁지겁 먹고 회복, 볼 반짝임 강조.
- 소량 주유: 작은 손인사 후 짧게 퇴장.
- 가득 주유: 몸이 더 동그랗게 부풀고 엉덩이 모션을 한 번 더.
- 장거리 출발 전: 볼을 부비는 설레는 반응.
- 출발 후: 위젯 가장자리에 일부 몸과 반짝임만 잠깐 남았다가 사라짐.

주유량·가득 여부·연료 급증 등을 실제로 얻을 수 있을 때만 해당 분기를 사용한다. 원본의 10L, 10%, 200km는 아직 확정된 앱 판정 임계값으로 취급하지 않는다.

## 현재 UI와 연결

- 경로 설정 직후 추천: 기존 이유 말풍선을 담당. 완료용 춤을 재사용하지 않는다.
- 지나치기 전 주행 안내: 현재 시안처럼 큰 캐릭터 없이 판단 이유와 두 버튼을 우선한다.
- 상세 분석: 정적인 설명 보조.
- 주유 완료: 별도 화면/상태와 한 번 재생되는 포즈 시퀀스를 추가했다. 보통 2초, 소량 1초, 가득/회복 2.4초다.

전달본은 원본 PNG 포즈와 짧은 위치/회전 애니메이션으로 구성했다. 원본의 리깅된 Rive/Lottie 제작까지 완료한 것은 아니다. 소량은 손인사 위주, 가득/회복은 기본 시퀀스를 더 길게 재생하고 말풍선을 바꾼다. 장거리 출발은 정적인 준비 인사다. 연료 감지/주유 확정은 기존 앱에서 연결해야 한다. Android는 상태의 단조 시계 시작 시간으로 현재 포즈를 구해 화면 재생성 때 처음부터 다시 시작하지 않는다.
