# 뽀동이 실제 프레임 애니메이션 · 2026-11-10

사용자가 지정한 [원본 참고](https://claude.ai/artifact/F1hvn6xzMmDncVC8rWj8gY#page-003e6cf4d7ba)의 손인사·볼 비비기·뒤돌기와 상황별 반응을 바탕으로 GPT에서 새 정차 프레임 64장을 생성하고 차분한 기본 8장을 유지했다. 원본 GIF는 9프레임 × 180ms = 1.62초다. 이번 전달본은 정차 4동작 × 16프레임 + calm 8프레임이며, 이전 정지 포즈의 CSS 회전 방식은 실행 경로에서 제거했다.

| 클립 | 새로 그린 동작 | 원본 재생 시간 |
| --- | --- | --- |
| calm | 작은 숨쉬기, 눈 깜빡임 | 1초, 이후 5초 쉬고 반복 |
| recommend | 오른손으로 가리키기, 고개 끄덕이기 | 1.6초, 1회 |
| small | 왼손 인사, 고개 기울이기 | 1.6초, 1회 |
| full | 웅크려 준비 → 양팔 크게 펴며 기뻐하기 → 천천히 내려오기 | 2초, 1회 |
| recovery | 지친 표정 → 숨 들이마시기 → 큰 기지개 → 안도 | 2초, 1회 |

일반 주유는 small 동작 후 마지막 프레임을 유지해 총 2초, 소량은 1.6초, 가득/회복은 마지막 프레임 유지까지 총 2.4초의 이벤트로 처리한다. 종료 후에는 calm으로 정착한다. 이는 8~10fps의 스프라이트 애니메이션이며 Rive/Lottie 리깅이나 30fps 영상은 아니다.

## 메시지와 위치

메시지가 있으면 뽀동이는 항상 표시한다. 추천/주유 후에는 말풍선 옆, 주행 위젯과 경유지 추가·상세·설정에서는 작은 머리줄 아바타다. 주행/주행 상태 미확인에서는 큰 손짓을 하지 않고 작은 calm만 사용한다. 출발하면 큰 동작을 즉시 취소하며, 다시 정차해도 이전 주유 인사를 재생하지 않는다. 소리는 없다.

characterEnabled=false 또는 접근성 모션 줄이기에서는 calm 첫 프레임을 계속 표시한다. 주유 이벤트는 이 경우에도 정상 종료한다. 동일 이벤트 ID는 다시 처리하지 않는다. Android 호스트는 seenIds와 설정을 저장하고, 동일 프로세스 화면 재생성에서는 단조 시계 기반 startedAtMs를 보존한다. 프로세스 재시작 뒤 celebration은 비운다.

## 파일과 구현

- web/animation-lab.html: 다섯 동작 비교 및 개별 재생/다운로드.
- web/assets/animation/*.webp: 투명 배경, 손실 없는 1회 재생 파일.
- web/assets/animation/podong-atlas.png: 256×256 셀 72장. 런타임은 manifest 좌표를 사용한다.
- web/animation-data.js, podong-animation.js: 실제 프레임 좌표와 Canvas 재생기. 외부 라이브러리 불필요.
- Android PodongClips.kt, PodongAnimation.kt, drawable-nodpi/podong_atlas.png: 같은 원본·프레임 타이밍의 Compose Canvas 재생기. 추가 애니메이션 의존성 없음.
- PROVENANCE.json, generation-request.json: 생성 출처와 동작 요청 기록.

과거 생성 임시 폴더는 배포에 포함하지 않는다. 이 역사적 아틀라스를 다시 내보낼 때는 `tools/export-animation-assets.py CURATED_RUN_DIR [IMG2WEBP_EXECUTABLE]`로 입력과 인코더 경로를 명시한다. 현재 소프트 선셋 자산은 `web/assets/sunset/`과 `tools/generate-sunset-motion.cjs`를 기준으로 하며 앱 실행에 이미지 생성 도구가 필요하지 않다.

차량 연료·주유 확정·내비 콜백은 기존 앱에서 연결해야 한다. 실제 Pleos 기기 재생과 순정 지도 위 표시 권한은 아직 검증하지 않았다.

## 표현 확대 후속 수정

사용자가 어색하고 동작이 작다고 피드백해 정차 동작을 16프레임의 한 가지 큰 동작으로 다시 생성했다. 빠른 뒤돌기와 앞보기 전환을 없애고 준비-최대 표현-회복의 흐름으로 바꿨다. 팔을 뻗을 때 캐릭터가 좌우로 밀리지 않도록 발 중심으로 정렬한다. 각 클립 전체에 동일한 표시 영역을 사용해 프레임마다 크기를 맞추지 않는다. 정차 캐릭터는 웹 210px / 네이티브 190dp, 주행 아바타 크기는 유지한다.

비교 페이지의 반복 미리보기는 동작을 관찰하기 위한 기능이다. 실제 차량 UI의 주유 인사는 여전히 한 번만 재생한다. 16프레임은 실험적 행 생성 범위이며 더 많은 프레임 자체가 품질 보증은 아니다. full의 자동 인접 변화량 경고(0.0095 < 0.01)를 기록했고, 원본과 추출 결과에서 팔·몸 동작 흐름을 확인했다. 향후 완전한 60fps 변형이 필요하면 별도 리깅 제작이 필요하다.
