# 뽀동이 V2 손 교정과 상황별 키포즈

2026-11-12 사용자 피드백에 따라 최초 V2 마스터의 손 구조를 다시 만들었다. 왼팔과 손이 겹친 두 덩어리처럼 보이던 부분과 반대쪽의 손가락처럼 보이는 분리 요소를 제거했다.

## 고정할 해부 규칙

- 팔은 몸에서 직접 이어지는 짧은 한 덩어리다.
- 손은 손가락 없는 둥근 장갑 한 덩어리다.
- 분리된 손 조각, 겹친 팔 덩어리, 손가락처럼 보이는 동작선을 쓰지 않는다.
- 한 포즈에서 팔은 최대 두 개만 보이며 양발은 몸과 안정적으로 연결한다.

## 완성 상태 구분

web/podong-v2-motion-lab.html은 위 키포즈에 CSS 마이크로 모션을 적용한 UX 검토용 화면이다. 프레임 간 움직임이 그려진 완성 애니메이션이나 운영 아틀라스가 아니다.

키포즈가 승인되면 기존 고정 뷰포트와 타이밍 규칙으로 calm 8프레임과 표현형 16프레임 4종, 총 72프레임을 만든다. 그 뒤 웹과 Android의 아틀라스, 타이밍, reduced-motion 자원을 동시에 교체하고 검증한다. 그 전까지 현재 승인된 운영 아틀라스는 유지한다.

## 이미지 생성 방식

내장 imagegen의 참조 이미지 편집 방식으로 동일한 황금빛 3D 클레이 정체성을 유지하면서 각 포즈를 제작했다. 모든 프롬프트에 연속된 짧은 팔, 둥근 장갑, 분리 조각과 추가 팔다리 금지를 명시했다. 원본 생성 파일은 Codex 생성 이미지 폴더에 유지하고 프로젝트에는 별도 버전 이름으로 복사했다.
