## 리뷰와 수정

별도 리뷰에서 지적한 경로 진행 맥락 유실과 Android 화면 재생성 시 모션 재시작을 수정했다. 후속 리뷰에서 중요한 회귀 없음 확인을 받았다.

Android는 모션 시작 시간을 상태에 기록하고 현재 단조 시계 시간으로 포즈를 계산한다. 같은 프로세스에서 화면이 재생성되어도 재생 시간을 초기화하지 않는다. 프로세스 재시작 시에는 인사를 복원하지 않는 호스트 계약을 문서화했다.
