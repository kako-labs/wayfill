# 2026-11-10 UI 수정

사용자가 승인한 방향: 숫자보다 “왜 지금 이 주유소에 들러야 하는지”를 먼저 설명한다.

- 팝업 순서: 주유 필요 이유 → 주유소와 경로 추가 시간 → 여기서 주유하기 / 계속 가기.
- “30km만 남아요”, 근거 없는 “마지막 안전”, “괜찮아요” 표현을 없앤다.
- 초기 예시: 주행 가능 75km, 목적지 95km. A 20km(+1분), B 60km(+3분), C 92km(+5분). 중간 주유가 필요하며 도달 가능한 A/B 중 더 가까우면서 추가 시간이 짧은 A를 추천한다.
- 주행 중 예시: 위 경로를 57km 진행한 시점. 주행 가능 18km, 목적지 38km, B 3km 앞, 다음 C 35km 앞. B를 지나면 C까지 약 17km 부족할 수 있어 안내한다.
- 주유소별 남은 거리는 해당 주유소에 도착했을 때의 예상값이며 주유 전 기준이다. 실제 경유 접근 거리까지 포함한 재계산은 앱 코드 연동 시 필요하다.
- 다음 주유소까지 연료 부족 문구는 해당 경로와 도달 가능성 데이터가 있을 때만 표시한다. 불확실하면 “마지막”이라고 단정하지 않는다.
- 시안 수치는 설명용이며 실제 차량/주유소 데이터와 연결되지 않았다. 버튼은 화면 시안이며 내비 연동은 하지 않는다.
- 이전 HTML/PNG는 `before/`에 보존했다.
