# Soft sunset assets and motion

The owner supplied the chosen home and road-ribbon Podong references on 2026-11-12. Originals are retained in `design/approved-sunset/`. Built-in image generation was used for transparent extraction, the clean scenic background, and four newly drawn sprite sheets. No CLI image API or user API key was used.

## Files and playback

- `podong-sunset.png`: approved portrait extraction, retained for icon/notification art.
- `sunset-forecourt.png`: scenic background without text, panels or character.
- Product motion uses `podong-calm-sheet.png` plus distinct `podong-recommend-sheet.png`, `podong-small-sheet.png`, `podong-full-sheet.png`, and `podong-recovery-sheet.png`. Calm is the original RGBA 4×4 grid at 1254×1254. Each expressive sheet is an RGBA 8×4 grid at 1774×887 with 32 separately drawn poses. `podong-wave-sheet.png` is retained only as the superseded shared-wave source.
- Web and Android render the same absolute-time timeline. Active parked gestures use a frame-synced render loop and at most 45ms smoothstep overlay between adjacent cells; calm sleeps through its long hold. Moving, Unknown, reduced-motion, and disabled-motion states remain on the first calm frame.
- `sunset-motion-data.js`: selected cells and durations. `tools/generate-sunset-motion.cjs --write` produces Android `SunsetMotion.kt`; package verification rejects drift.
- Native/web PNG copies are byte-identical. Grid bounds use integer divisions of the full sheet, keeping a fixed per-cell viewport without per-frame auto-cropping.

Calm uses six selected cells with one blink in six seconds. Recommendation, small refuel, full refuel, and low-range recovery each use a distinct 32-frame sheet. Small refuel lasts 1.6 seconds, recommendation 1.8 seconds, and full/recovery last 2.4 seconds including the settling hold. Web and Android use the same sheet bytes and timing manifest. New sheets do not replace or mutate the historical 72-frame atlas in the old lab.

The authored 32-pose sheets replaced rejected optical-flow and crossfade intermediates, which produced transient face/hand distortion. `clean-sprite-alpha.ps1` keeps the center-connected character in each cell and removes disconnected generation residue before installation.

The new character has the approved round yellow body and road band. We examined contact sheets and actual browser/native renders. The expressive clips provide 15–20 authored poses per second while the player remains synchronized to the display clock; this is still a sprite animation, not a rigged 60fps model. Actual device-size review remains part of PLEOS verification. No audio is generated by the character player. System notification sound remains an OS setting.

## Generation prompt set

Common sprite prompt: preserve the approved round golden body, short limbs, glossy brown eyes, rosy cheeks, and glowing dashed road ribbon. Create an exact 4-column/4-row grid of 16 whole-character sequential poses, same scale/camera/light/baseline, transparent canvas, safety margins, no gutters/borders/numbers/background. Keep body center steady; animate facial expression and arms, not whole-image rotation. Each cell must be independently usable by fixed grid cropping.

- **Wave:** neutral closed-mouth smile → small anticipation → one arm raises and waves with an open smile → brief smiling eyes → arm lowers and calm smile returns. Stable road ribbon, no spinning or particles.
- **Calm:** arms down, closed-mouth smile, eyes open in frames 1–4, half lowered at 5, closed at 6–7, half open at 8, open again at 9–16. No waving/bouncing or changing body scale.
- **Full:** calm → slight anticipation squat → both arms open with happy eyes and smile → gently settles → arms return down. Feet remain on the same baseline; no big jump or spinning.
- **Recovery:** a little tired with lowered arms/half eyes → gentle crouch → stretches both arms upward/outward with a happy face → settles into a contented pose. No sick expression, accessories or camera motion.

Exact extraction/background prompts are in `design/approved-sunset/README.md`. The source reference is the approved PNG, not the old character atlas. Playback, event deduplication, elapsed-time seeking and driving/reduced-motion cancellation are code responsibilities, not properties guaranteed by an image generator.
